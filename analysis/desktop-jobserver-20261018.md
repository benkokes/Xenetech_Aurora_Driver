# Normal JobServer window — October 18, 2026

The normal launcher now opens a JobServer window rather than the manual JBS
diagnostic queue. CorelDRAW continues to use the installed native printer and
its first-screen raster/vector Properties. The window shows each received
document, its own settings and its conversion/delivery result.

Each launch begins in capture-only mode. Enabling laser printing creates a
fresh session and switches only future LPR receives into its dedicated capture
folder. Earlier captures and session folders are history only. No historical
worker is reconstructed. A request that began before the switch retains its
original capture-only destination even if it finishes after enabling.

New live-session captures automatically pass through the existing native
converter, encoder, durable queue and sender. Selecting capture-only finishes
the current print and holds later session captures; subsequent receives go to
the capture-only folder. Cancel applies only before a print is selected for
conversion. Closing waits for the current delivery and all accepted LPR
receives. A crash never causes a repeat upload: interrupted delivery records
are recovered under the controller lock and uncertain outcomes require an
operator observation. Device uncertainty markers remain enforced.

Connection checks use only the observed status request on port 29. They do not
establish physical readiness. Optional sign-in startup manages a single named
HKCU Run value, preserves conflicting entries and still starts capture-only.
Startup was left disabled on this PC.
